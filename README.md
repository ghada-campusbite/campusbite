# CampusBite

منصة طلبات مسبقة لمطاعم الجامعة: الطالب يطلب من تطبيق الموبايل، والمطعم يجهّز، والاستلام بكود وقت البريك.

- `backend/` — NestJS + Prisma + PostgreSQL (الحسابات بالقرش على السيرفر، سعة الاستلام أتوميك)
- `dashboard/` — لوحة المطعم + لوحة الأدمن (Next.js)
- `student-app/` — تطبيق الطالب (Expo / React Native، عربي RTL)
- `deploy/` — دليل النشر والأمان: شوف `deploy/DEPLOY.md` و `deploy/GAPS.md` و `deploy/SECURITY.md`

الحالة بصراحة في `deploy/GAPS.md`.
