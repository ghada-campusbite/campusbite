# CampusBite: إيه اللي اتعمل وإيه اللي فاضل

> **الحالة بصراحة:** المنصة كاملة ومترابطة محليًا وكل اختباراتها خضرا، لكنها **مش جاهزة للإنتاج**. اتنشر نشر تجريبي مجاني (تفاصيله تحت)، والإيميل الحقيقي والإشعارات ماتجرّبوش على مزوّد حقيقي. الملف ده بيفرّق بين "اتحقق محليًا" و"لسه".

## اللي فاضل (الفجوات)

1. **النشر الحقيقي على Neon + Render.** الحسابات الأربعة اتعملت (مجاني، بإيميل بس)، لكن مفيش قاعدة بيانات Neon ولا سيرفس Render اتنشئوا جواهم، لأن الرجوع لأي حساب محتاج إذن منك الأول. من غير الخطوة دي الكود ماتأكدش على Postgres مستضافة ولا تحت HTTPS حقيقي.
2. **APK أندرويد.** البيلد المحلي بـ Gradle وقف عند حدود بيئة الشغل هنا (تنزيلات تقيلة). الطريق المتاح: EAS Build على حساب Expo بتاعك (مجاني)، وده كمان محتاج إذن دخول للحساب + إن كل دخول لـ Expo بيبعت كود على إيميلك.
3. **الإيميل الحقيقي.** الباك إند جاهز على Resend (مجاني، بس HTTP)، لكن مفيش حساب Resend لأنه خامس حساب، خارج الأربعة اللي وافقتي عليهم. وعليه اختبار e2e لإيميل "إعادة تعيين كلمة سر الموظف" ماتعملش. لو موافقة نعمله، محتاج موافقتك على اشتراك جديد.
4. **الإشعارات Push على جهاز حقيقي.** كود الإشعارات موجود (Expo push tokens) لكن ماتجرّبش على موبايل فعلي. بيتأكد بشكل نهائي مع الـ APK أو Expo Go.
5. **`EXPO_PUBLIC_API_URL` في نسخة الويب من تطبيق الطالب.** بيلد الويب مش بيحقن المتغير، وفيه fallback بـ `__CB_API_URL`. مهم بس لو هتنشري التطبيق كويب؛ نسخة الموبايل بتقرأ المتغير وقت البيلد عادي.
6. **تأمين منفذ الـ API عند النشر.** الإعداد اتجرّب خلف بروكسي حقيقي (`TRUST_PROXY_HOPS=1`)، لكن لازم وقت النشر قفل الوصول المباشر للـ API فايروول، زي ما `SECURITY.md` شارح بالظبط.

## ملاحظات صغيرة
- تسجيل الدخول عليه rate limit (5 محاولات/دقيقة لكل IP)، ده مقصود.
- بيانات الديمو (`node test/seed-demo.cjs`) كلها وهمية وواضح إنها تجريبية، وكلمات سرها مكتوبة في السكربت نفسه، متستخدموهاش في نشر حقيقي.
- تشغيل اختبارات e2e بيعمل reset للداتابيز، فبعدها أعيدي تشغيل سيد الديمو لو عايزاه.

## الخلاصة
كل حاجة اتبنت واتأكدت على جهاز واحد محليًا. الخطوة الجاية الوحيدة هي النشر، وهي واقفة على إذنك للرجوع للحسابات، مش على شغل كود.

## حالة النشر الفعلي (27 نوفمبر 2026)

اتنشر بالخطط المجانية بس، وده نشر تجريبي مش إنتاج:

- **قاعدة البيانات:** Neon (Frankfurt)، 9 migrations اتطبقت، والتطبيق بيتصل بيوزر محدود الصلاحيات (`campusbite_app`).
- **الـ API:** https://campusbite-api-s86z.onrender.com/api/v1 ، فحص `/health` رجّع `ok`، و`/universities` و`/canteens` بيردوا (القاعدة فاضية).
- **لوحة التحكم (مالك + أدمن):** https://campusbite-dashboard.onrender.com ، الصفحة بتفتح. دخول الأدمن لسه ماتجرّبش لأن حساب الأدمن لسه ماتعملش.
- **تطبيق الطالب:** APK تجريبي (preview) على EAS Build متوصل بالـ API الحي. ماتجرّبش على موبايل حقيقي لسه.
- **الكود:** https://github.com/ghada-campusbite/campusbite

### اللي لسه / حدود النشر المجاني
- Render المجاني بينام بعد فترة خمول، وأول طلب ممكن ياخد 50 ثانية أو أكتر.
- الصور المرفوعة بتتخزن على قرص مؤقت في Render المجاني وبتضيع مع كل نشر أو إعادة تشغيل. محتاج تخزين دائم (S3/R2) قبل الإنتاج.
- حساب الأدمن ماتعملش، ومفيش مطاعم أو بيانات تجريبية على الـ API الحي.
- الإيميل الحقيقي (Resend) ماتفعّلش، وبالتالي تأكيد الإيميل واسترجاع كلمة السر مش شغالين على النشر الحي.
- الإشعارات ماتجرّبتش على مزوّد حقيقي.
- الـ APK ده توزيع داخلي للتجربة، مش نسخة متجر.
