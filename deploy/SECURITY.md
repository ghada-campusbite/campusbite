# مراجعة أمنية — CampusBite

> دي مراجعة كود داخلية (بتاعتي أنا). **مش بديل لاختبار اختراق مستقل**، ومحدش يقدر يضمن "صفر ثغرات". الهدف إننا نقفل الثغرات الشائعة ونعرف بوضوح اللي لسه مفتوح.

## اللي اتراجع واتأكدنا منه
- **الصلاحيات / IDOR:** كل endpoint عليه Guard بدور المستخدم، وكل query مقيّد بصاحبه (`userId` للطالب، `canteenId` للموظف). مفيش طريقة لطالب يشوف أو يلغي طلب غيره، ولا لمطعم يعدّل منيو أو طلبات مطعم تاني.
- **الأسعار:** بتتحسب من الداتابيز دايمًا. الـ validation بيرفض أي حقل زيادة (`forbidNonWhitelisted`) وكل الـ IDs UUID.
- **الباسوردات والتوكنات:** argon2، وrefresh token بيتغير كل مرة ومتخزن hash، والـ access token عمره 15 دقيقة.
- **اللوحة:** التوكنات في cookies httpOnly + SameSite=Strict، وفحص Origin على أي تعديل، والـ proxy بيسمح بـ endpoints محددة بس.
- **النقل:** HTTPS تلقائي، وHSTS، وCSP.

## اللي اتصلّح في المراجعة دي
1. **Rate limit مشترك:** اللوحة كانت بتكلم الـ API من IP واحد، فمحاولات الدخول كانت هتتحسب على كل الموظفين مع بعض (ومهاجم يقدر يقفلها على الكل). دلوقتي الـ IP الحقيقي بيتمرر.
2. **تسريب وجود الإيميل بالتوقيت:** الدخول بإيميل مش موجود كان أسرع. دلوقتي دايمًا فيه عملية تحقق واحدة.
3. **سباق في تغيير حالة الطلب:** اتحوّلت لتحديث ذرّي، فمفيش قفزة حالة غلط لو طلبين جم مع بعض.
4. **إغراق المطعم بطلبات وهمية:** حد أقصى 3 طلبات شغالة للطالب + rate limit على إنشاء الطلب.
5. **خوارزمية JWT** متثبتة على HS256 صراحةً.
6. **التطبيق** بيرفض يشتغل في النسخة الفعلية لو الـ API مش https.
7. **حذف الحساب من التطبيق** (Apple وGoogle بيطلبوه): بيمسح البيانات الشخصية ويلغي الطلبات الشغالة.
8. اختبارات جديدة لكل ده (إجمالي 17 اختبار).

## لسه مفتوح (قرارك قبل الإطلاق)
- ~~مفيش نسيت الباسورد / تأكيد إيميل~~ ✅ اتعمل: كود 6 أرقام صالح 15 دقيقة، 5 محاولات بس، وبيتخزن مشفّر (HMAC)، والطلب مقفول قبل التأكيد. لسه محتاج Resend يتظبط بدومينك.
- **الدفع:** حاليًا عند الاستلام. أي دفع أونلاين = مراجعة متخصصة وبوابة مرخّصة (Paymob/Fawry)، ومتخزنيش بيانات كروت أبدًا.
- **قفل الحساب بعد محاولات فاشلة:** الحماية حاليًا بالـ IP بس (5/دقيقة). هجوم موزّع على حساب واحد مش متغطي.
- **الدور في التوكن** بيفضل صالح لحد 15 دقيقة بعد ما الأدمن يغيّر الموظف. مفيش endpoint لتعطيل موظف لسه.
- **مفيش مراقبة ولا تنبيهات:** ركّبي Sentry أو ما يعادله، وراقبي `docker compose logs`.
- **الباك أب** غير مشفّر وعلى نفس السيرفر: شفّريه وانسخيه برا (`chmod 700 backups`).
- **سياسة خصوصية وشروط استخدام** مطلوبين للمتاجر ولقانون حماية البيانات الشخصية المصري (151/2020).
- **اختبار اختراق مستقل** قبل ما توصلي لعدد مستخدمين كبير، أو أي دفع.
